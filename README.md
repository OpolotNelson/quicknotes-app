# QuickNotes

QuickNotes is a simple, responsive web application that allows users
to create, organise, search and delete notes. Notes are grouped into
Personal, Work and Study categories, and saved in the browser so they
remain available after refreshing the page.

## Features

- Add notes with Personal, Work or Study categories.
- Display notes with their category and creation date.
- Validate empty notes and notes exceeding 200 characters.
- Delete individual notes.
- Search notes without case sensitivity.
- Display the total number of notes.
- Save and restore notes using browser localStorage.
- Responsive layout for desktop and mobile screens.

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.
4. Add, search and delete notes in your browser.

You can also open `index.html` directly in a browser.
